# **Star Guard** (prototype rom)

###### developed by Loren Schmidt



***The Discovery:***  Before SNK's NEO GEO home arcade game console, Williams had prototyped a version of their arcade hardware for the home.   Found inside a cardboard box behind a rusted shelving unit in a suburban Chicago warehouse, a large and tall prototype console was found alongside thick, commercial-grade ROM cartridges for Sinistar, Robotron: 2084, and Joust.   

***The Hardware:***  Nicknamed "The Tower," the unit featured a heavy-duty vertical chassis housing stacked arcade-spec PCBs, twin industrial controller ports, and an oversized top-loading slot built to accommodate a massive stack of rom chips.    The PCB's inside were modified for size and based on PCB version used in Blaster Duramold arcade games.

***The Killer App:***  Tucked near the bottom of the box was an unmarked, hand-labeled EEPROM chip simply titled "Star Guard".   Turns out, it was Williams first home-exclusive game intended for the unreleased console.   It's a blazing fast, multi-directional shooter blending frantic Robotron mechanics with atmospheric deep-space dread.   Developed by a very young but talented artist and programmer Loren Schmidt, the game was lost until now.

***The Lost Legacy:*** Playtests confirmed "Star Guard" compared favorably with its arcade brethren, possessing the addictive loop and polish that would have rivaled NES launch titans had the 1983 video game crash not abruptly terminated Williams' consumer hardware division.
